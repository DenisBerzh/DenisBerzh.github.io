# Berzhanin Denis — личный сайт

Чёрно-белое резюме и портфолио с портретом, движущимся именем, меню и интерактивными превью. В портфолио 12 примеров по трём направлениям: презентации, интерфейсы, айдентика и графика. Категории оформлены крупными строками: наведение показывает плавающее превью, нажатие фильтрует общую сетку. Первая работа выбранного направления занимает всю ширину. Презентации идут первыми: «Страховой рынок», «Обработка заказов», Creator Gym, Unity of Command; ещё три скрыты в раскрывающейся кнопке «Ещё». Затем Learning Atlas, EON VPN и три работы айдентики. Сохранены 14 исходных изображений и две увеличенные версии интерфейсов. Апскейл выполнен встроенным imagegen: мелкие подписи могут отличаться; в просмотре есть ссылка на исходник. EON VPN можно прокручивать на телефоне. Полные презентации не предоставлены. Личные сведения пока не заполнены.

Статический сайт без сборки и зависимостей. Для локального просмотра запустите HTTP-сервер в этой папке. GitHub Pages публикует корень ветки main репозитория DenisBerzh/DenisBerzh.github.io по адресу https://denisberzh.github.io/.

Содержимое: index.html. Оформление: styles.css. Взаимодействия: app.js. Фото: assets/portrait.png. Прочитайте USER-BRIEF.md, AGENTS.md и DESIGN.md перед изменениями.

## Источники

- [Dennis Snellenberg](https://dennissnellenberg.com/): композиция первого экрана, движущееся имя, крупные строки категорий, плавающее превью с вертикальным переключением изображений, круглая кнопка меню и тёмный финальный раздел. Из сохранённого источника прочитаны initMousePos и initVisualFilter; поведение адаптировано в собственный небольшой JavaScript без GSAP/jQuery. Слайды и фото предоставлены пользователем. Чужие демонстрационные проекты заменены его примерами.
- [Kinetics](https://kinetics.colorion.co/): Momentum Marquee, Magnetic Button, Stagger Entrance и Pointer Tooltip адаптированы в CSS и JavaScript. Следование превью использует lerp .18 с поправкой на частоту кадров; цикл работает только при наведении. Предусмотрены пауза движения и системная настройка reduced motion.
- [21st.dev Tabs](https://21st.dev/community/components/s/tabs) и [Component Gallery Tabs](https://component.gallery/components/tabs/): проверка паттерна переключения категорий. Здесь используются обычные кнопки-фильтры с aria-pressed и aria-controls, а не отдельные вкладки-панели. Библиотеки не устанавливались.
- [21st.dev Navigation Menu](https://21st.dev/community/components/s/navigation-menu) и [Component Gallery Navigation](https://component.gallery/components/navigation/): просмотр структуры навигации. Меню реализовано нативным HTML dialog без установки библиотек.
- [Linear DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md): исходные рекомендации по типографике и отступам, сохранённые без изменений. Текущий запрос пользователя на монохромное оформление зафиксирован отдельно в USER-BRIEF.md. Лицензия исходного файла сохранена в DESIGN-LICENSE.txt.
