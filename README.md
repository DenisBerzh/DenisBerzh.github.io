# Berzhanin Denis — личный сайт

Чёрно-белое резюме и портфолио с портретом, движущимся именем, меню и интерактивными превью. В портфолио 12 примеров по трём направлениям: презентации, интерфейсы, айдентика и графика. Категории оформлены крупными строками: наведение показывает плавающее превью, нажатие фильтрует общую сетку. Первая работа выбранного направления занимает всю ширину. Презентации идут первыми: «Страховой рынок», «Обработка заказов», Creator Gym, Unity of Command; ещё три скрыты в раскрывающейся кнопке «Ещё». Затем Learning Atlas, EON VPN и три работы айдентики. Сохранены 14 исходных изображений и две увеличенные версии интерфейсов. Апскейл выполнен встроенным imagegen: мелкие подписи могут отличаться; в просмотре есть ссылка на исходник. EON VPN можно прокручивать на телефоне. Полные презентации не предоставлены. Добавлены подтверждённые личные сведения и контакты.

Статический сайт без сборки и зависимостей. Для локального просмотра запустите HTTP-сервер в этой папке. GitHub Pages публикует корень ветки main репозитория DenisBerzh/DenisBerzh.github.io по адресу https://denisberzh.github.io/.

Содержимое: index.html и resume.html. Оформление: styles.css. Общая навигация и анимации: motion.js, motion-boot.js и motion.css. Портфолио: app.js. Просмотр сертификатов: resume.js. Фото: assets/portrait.png. Прочитайте USER-BRIEF.md, AGENTS.md и DESIGN.md перед изменениями.

Текст «Резюме & портфолио» на первом экране и пункт «Резюме» в меню ведут на отдельную страницу с портретом. Вместо заглушки опубликовано резюме с подтверждёнными образованием, проектами, наградами и языком; доступен одностраничный PDF с портретом. Готовый вариант из Figma пока не предоставлен. Академические документы разделены на три награды и три карточки участия и обучения. Крупные I, II и III показывают степень или место. Диплом и сертификат докладчика «Маркетинг России» объединены в одну карточку, оба файла доступны. Сохранены все семь оригинальных PDF с обложками, датами и подтверждёнными названиями. Обложки открываются в HTML dialog; PDF можно открыть отдельно. Совместный диплом сохраняет указание соавтора. assets/certificates/manifest.json содержит соответствие исходных имён, путей и SHA-256 оригиналов. PDF скопированы без изменений; превью одного диплома повёрнуто для удобного чтения.

Перед остальными документами расположен отдельный блок «Английский язык»: IELTS Academic (6.0/9, B2) первым, Duolingo English Test (110/160, B2) вторым. В этих двух публичных копиях по выбору пользователя закрыты даты рождения и личные номера: Candidate ID, Candidate Number, Test Report Form Number и Duolingo Certificate ID, включая индивидуальную ссылку проверки. Копии сведены в изображение внутри PDF, чтобы скрытые значения нельзя было восстановить из текстового слоя; исходные PDF не менялись и не опубликованы. Превью и просмотр используют только публичные версии. В манифесте сохранены отдельные хеши исходника и публичной копии. Всего на странице восемь карточек: два языковых и шесть академических, содержащие девять PDF. В текущих языковых копиях нет текстового слоя, аннотаций или вложений; превью не содержат EXIF. Старые коммиты GitHub ещё содержат прежние публичные копии с номерами тестов. История не переписывалась.

## Источники

- [Dennis Snellenberg](https://dennissnellenberg.com/): композиция первого экрана, движущееся имя, крупные строки категорий, плавающее превью с вертикальным переключением изображений, круглая кнопка меню и тёмный финальный раздел. Текущий слой анимаций написан заново по наблюдениям в живом браузере: прелоадер, меню, метка курсора, превью, переходы и footer. Сохранённые исходники референса для этой версии не использовались. Слайды и фото предоставлены пользователем. Чужие демонстрационные проекты заменены его примерами.
- [Kinetics](https://kinetics.colorion.co/): Momentum Marquee, Magnetic Button, Stagger Entrance и Pointer Tooltip адаптированы в CSS и JavaScript. Новый контроллер использует независимые скорости следования курсора и превью с поправкой на частоту кадров; цикл останавливается после достижения цели. Магнитные кнопки используют собственную пружину. Предусмотрены пауза движения и системная настройка reduced motion.
- [21st.dev Tabs](https://21st.dev/community/components/s/tabs) и [Component Gallery Tabs](https://component.gallery/components/tabs/): проверка паттерна переключения категорий. Здесь используются обычные кнопки-фильтры с aria-pressed и aria-controls, а не отдельные вкладки-панели. Библиотеки не устанавливались.
- [21st.dev Navigation Menu](https://21st.dev/community/components/s/navigation-menu) и [Component Gallery Navigation](https://component.gallery/components/navigation/): просмотр структуры навигации. Меню реализовано нативным HTML dialog без установки библиотек.
- [Linear DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md): исходные рекомендации по типографике и отступам, сохранённые без изменений. Текущий запрос пользователя на монохромное оформление зафиксирован отдельно в USER-BRIEF.md. Лицензия исходного файла сохранена в DESIGN-LICENSE.txt.

## Удобство портфолио

На виду две презентации: «Страховой рынок» и «Обработка заказов». Кнопка «Ещё 5 презентаций» раскрывает остальные в общей сетке; счётчик обновляется. Категория прокручивает к результатам с кнопкой «Все работы». Превью категорий без круга, метка «Смотреть» остаётся над карточками. Вступление длится около 0,85 секунды, его можно пропустить нажатием или клавишей; прокрутка на это время заблокирована. Фон первого экрана #686868; белые подписи читаются лучше. Для показа используются адаптивные WebP-копии; оригинальные изображения доступны по прежним ссылкам. Сертификаты не менялись.
